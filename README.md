# Digital Earth: Light Pollution

An immersive interactive **Digital Earth** experience exploring global light pollution, its environmental impact, and practical solutions.

## Live Demo

Once GitHub Pages is enabled (Settings → Pages → Deploy from branch `main` / root), the site will be available at:

**https://trextrinorex.github.io/digital-earth-light-pollution/**

## Features

- Interactive 3D globe powered by Three.js
- Night-side city lights visualization (NASA-derived textures)
- Smooth orbit, zoom, and auto-rotate controls
- Atmospheric glow and starfield
- Educational panels covering:
  - What light pollution is
  - Environmental & ecological impacts
  - Human health effects
  - Energy waste & climate links
  - Practical solutions & dark-sky practices
- Fully responsive, dark immersive UI

## Tech Stack

- Vanilla HTML / CSS / JavaScript
- [Three.js](https://threejs.org/) (via CDN)
- NASA / Earth Observation Group inspired night-lights textures (via jsDelivr three-globe examples)

## Local Development

Simply open `index.html` in a modern browser, or serve the folder with any static server:

```bash
npx serve .
```
